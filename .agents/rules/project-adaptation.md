# Project adaptation

- Inspect repository instructions, manifests, routes, representative components, styles, tests, and commands before implementation.
- Record findings in the project profile and searchable code index, with file/symbol references.
- Follow actual project conventions. If context documents disagree with code, record the conflict and resolve it before relying on them.
- Index relevant areas; avoid dumping the entire repository. Refresh entries affected by code changes.
- For a new project, establish the stack and architecture from project requirements before scaffolding. The harness supplies neither.
