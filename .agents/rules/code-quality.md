# Code quality

- Follow existing semantics, component APIs, styling conventions, and dependency choices.
- Preserve keyboard use, focus visibility, labels, contrast, and meaningful document order.
- Implement relevant interaction and loading, empty, error, disabled, or selected states from the specification.
- Prefer resilient layout and real assets/fonts over absolute positioning or screenshot-based page content.
- Run the project's applicable checks. Add behavior tests where they provide useful coverage; avoid tests that only mirror markup.
- Keep changes scoped; record limitations and consequential assumptions.
