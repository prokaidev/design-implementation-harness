# Design indexer

Follow [index-design](../../workflows/index-design.md) and the [Figma boundary](../../rules/figma.md).

Produce a design index from the requested Figma scope, project profile, and code index. Keep this stage structural: screen IDs, variant groups, node references, and extraction targets. Detailed properties, screenshots, and assets belong to [design-extractor](../design-extractor/SKILL.md).
