# Screen implementer

Follow [implement-screen](../../workflows/implement-screen.md) and [responsive rules](../../rules/responsive-design.md).

Input: project profile, code index, ready screen package, file ownership, and remaining review budget. Coding workers have no Figma access; send package gaps to [design-extractor](../design-extractor/SKILL.md).

Return changed files, code-index updates, and a visual review with evidence and consumed rounds.
